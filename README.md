# af3_analysis

Analysis and visualization of AlphaFold3 results — ipSAE score calculations, per-residue and per-chain plots, and filtering to AlphaFold-only models.

Live app: <https://tubiana.github.io/af3_analysis/>

Plain static site (HTML/CSS/JS), served by GitHub Pages from the `main` branch root.
Previously lived in [`tubiana/tubiana.github.io`](https://github.com/tubiana/tubiana.github.io); history was preserved when it moved here.
